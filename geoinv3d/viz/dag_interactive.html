rock samples .csv · boreholes or map .shp (with .dbf .shx .prj) or .geojson — a saved model goes back into the editor above
Like the regions of MARE2DEM's model builder, in 3D. A body is an outline on the map extruded between two depths below the ground (or two elevations), straight down or dipping; a layer stack is a list of thicknesses, everywhere or inside an outline, its interfaces flat or tilted. Each carries a value per property of the loaded data — density (entered as rock density, inverted as the contrast to the reduction density), susceptibility, resistivity (Ω·m, inverted as log conductivity) — with a range and a weight. The inversion starts from this model, is pulled towards it (more strongly for a larger weight; fixed hardly moves) and keeps each part within its range; elsewhere the model is free. Sharp relaxes the smoothing across a part's boundaries so the model may jump there (like ModEM's covariance "tears"). Layers or bodies thinner than the mesh cells are mixed into them by volume, so none is lost; finer cells resolve them. The data still decide: compare the misfit with and without the model. Files are optional: whatever they are missing is left out, with a note in the result. See docs/geology_constraints.md.
Regularization & inversion parameters
How the models are coupled a choice of its own, separate from each model's regularization
Densities as rock densities (the Model step's reduction density is subtracted), resistivities in Ω·m (spread as a factor ×). Spreads left out: a tenth of the unit's contrast. A background unit at the reference with a tight spread (2.5 % of the largest contrast) is added unless one is named "background".
  • Data weights: uncertainty = percent × |d| + floor (set on each data card)
  • β (trade-off): initial value from an eigenvalue estimate, cooled until χ² ≈ number of data
  • α (smoothness weights): αs = 1; αx = αy = αz = 3 (length scales) for a single magnetic inversion, 1 otherwise
  • Model norms: p = [1, 1, 1, 1] for a single magnetic inversion (the most robust of 40 settings in the synthetic Lp study), p = [0, 2, 2, 1] (compact bodies) otherwise; IRLS thresholds tuned automatically
  • Joint inversion: equal data weights, coupling weight 1 (as strong as the regularization)
  • Group lasso + L2 (Utsugi 2025, set up for field data): cells weighed by volume × depth weight (β = 1) as in the other inversions, each datum by its error, λ2 = 0.3, λ1 for χ² = N on a 13-point sweep, then the two datasets balanced until each fits χ² = N; μ automatic. Manual mode has the paper's settings (sensitivity weighting, amplitude balance, L-curve).
Auto uses proven defaults plus an automatic β search and covers most cases. Switch to Manual if you have prior knowledge of the model style (smooth vs blocky) or the physical-property range.
Group lasso + L2 (Utsugi 2025)
φ = ½‖b − Zζ‖² + λ1 Σk √(βk² + ρk²) + ½λ2‖ζ‖² on sensitivity-weighted models (unit columns, γ = 2). The group norm selects a cell for both models or for neither, without making either property non-zero or asking for the same sign, so bodies line up where the data allow. λ1 is swept down from λ1,max (where both models are zero) with warm starts; λ2 is plain amplitude damping, not smoothness: small values give compact bodies with inflated values (λ2 = 0.01 inflated the synthetic body about six times), large ones spread it (λ2 = 1 also kept χ² above N for small errors). Try a λ2 sweep below. μ changes the speed of ADMM, not the result. No smoothness term. Bounds (below, or per model, e.g. susceptibility ≥ 0) are kept exactly by the ADMM. On field data with wide padding the paper's weighting (γ = 2) makes every cell equally cheap and the models leave the core (Karnataka: 67 % and 82 % outside); weighing the cells like the other inversions kept 12 % and 33 % outside. One λ1 serves both datasets, so χ² = N in total can hide an overfitted gravity model (0.45 N) and an underfitted magnetic one (2.4 N): the balance reweighs the two datasets until each fits χ² = N (0.96 and 1.02 N), and needs the sweep (not a fixed λ1).
Regularization
One job: the most probable model and samples of the posterior around it (randomized maximum likelihood). Compact: the bodies are compact and positive — the Lp model (magnetics: 0 to 1 SI unless you set an upper bound), and the spread of models like it (a Laplace approximation); sharp, for targets. Smooth: the smooth L2 regularization as a Gaussian prior — exact, and as wide as the data alone allow (deep, smeared bodies). The probability of a body is the share of samples above the threshold, which the 3D view can change afterwards. Gravity or induced magnetic data, single inversions; memory ≈ 16 bytes × data × cells, so thin the data to a few thousand.
φm = (1−α)/2·‖β‖² + α·‖β‖₁ on the depth-weighted model. α → 1 gives compact bodies, α → 0 spread-out ones (the L2 part is on the values: it is not a smoothness). The coordinate-descent solver computes the whole λ path from λmax and picks λ on it (L-curve by default); it needs gravity or magnetic data. The depth weighting wS1 / wS2 and the λ range are the coordinate descent’s: SimPEG IRLS weights the cells by its sensitivity weighting (√diag JᵀJ), the same as wS1. On our magnetic synthetic, α ≈ 0.8 with wS1 recovered the body best (wS2 pushed it too deep). There is no smoothness term, so norms and αx,y,z do not apply. Joint jobs run it by IRLS.
The focusing parameter e = scale × this percentile of |∇m| of the L2 model (default scale: 1 for MGS, 0.1 for TV), fixed once reweighting starts. MGS gives blocky, sharp-edged bodies but is very sensitive to e; set an upper property bound when you can. TV is milder: piecewise-smooth models.
φm = αs‖W m‖² + Σ αi‖W ∂im‖²: classic smooth least-squares inversion with sensitivity (depth) weighting. It gives smooth, blurred models with underestimated amplitudes; use it as a baseline or when no sharp contacts are expected. αx,y,z are length scales relative to αs, as for the other methods.
Model style (norms)
Regularization weights α
αx,y,z are length scales (SimPEG uses (α × smallest cell)² for the gradient terms). With αs as small as 0.0001 the smallness term hardly acts and sparse models turn into vertical columns that reach the bottom of the mesh; αs ≈ 0.1–1 gives compact bodies.
Depth weighting
Depth weighting sets the model-norm weight (z + z₀)−β/2 below the stations: β = 2 is Li & Oldenburg's value for gravity (3 for magnetics), and a smaller β makes deep cells dearer, so the model stays shallower while the mesh keeps its deep cells. A single magnetic inversion starts with depth weighting and β = : sensitivity weights make deep cells as cheap as shallow ones, and a broad anomaly then becomes a big deep block. Unlike sensitivity weighting it does not make the padding cells cheap. Not used by L1–L2, whose weighting is set above.
Trade-off parameter (β / λ)
L-curve and GCV do not rely on the data errors; each runs a sweep of fixed-β inversions (about 15 extra runs) unless the L1–L2 λ path already provides it. On our synthetics the L-curve matched χ² = N for sparse models, while GCV tended to over-fit. GCV needs gravity or magnetic data. Joint jobs use χ² = N.
