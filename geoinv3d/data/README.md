# Data shipped with geoinv3d

- `igrf14coeffs.txt`: the coefficients of the 14th-generation International Geomagnetic
  Reference Field (IGRF-14, IAGA Working Group V-MOD, 2024), Schmidt semi-normalised, degree
  1-13, epochs 1900-2025 and the secular variation for 2025-2030. Downloaded unchanged from
  https://www.ngdc.noaa.gov/IAGA/vmod/coeffs/igrf14coeffs.txt; used by `geoinv3d/methods/igrf.py`.
