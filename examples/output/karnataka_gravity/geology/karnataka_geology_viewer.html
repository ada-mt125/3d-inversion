Regularization & inversion parameters
  • Data weights: uncertainty = percent × |d| + floor (set on each data card)
  • β (trade-off): initial value from an eigenvalue estimate, cooled until χ² ≈ number of data
  • α (smoothness weights): αs = 1, αx = αy = αz = 1 (length scales)
  • Model norms: p = [0, 2, 2, 1] (compact bodies); IRLS thresholds tuned automatically
  • Joint inversion: equal data weights, cross-gradient weight = 1
  • Group lasso + L2 (Utsugi 2025): sensitivity-weighted models, gravity scaled to the magnetic amplitude, λ2 = 0.3, λ1 at the L-curve corner of a 13-point sweep (χ² = N if there is no corner), μ automatic
Auto uses proven defaults plus an automatic β search and covers most cases. Switch to Manual if you have prior knowledge of the model style (smooth vs blocky) or the physical-property range.
Group lasso + L2 (Utsugi 2025)
φ = ½‖b − Zζ‖² + λ1 Σk √(βk² + ρk²) + ½λ2‖ζ‖² on sensitivity-weighted models (unit columns, γ = 2). The group norm selects a cell for both models or for neither, without making either property non-zero or asking for the same sign, so bodies line up where the data allow. λ1 is swept down from λ1,max (where both models are zero) with warm starts; λ2 is plain amplitude damping, not smoothness: small values give compact bodies with inflated values (λ2 = 0.01 inflated the synthetic body about six times), large ones spread it (λ2 = 1 also kept χ² above N for small errors). Try a λ2 sweep below. μ changes the speed of ADMM, not the result. Unconstrained first version: no bounds, no smoothness, no cross-gradient.
Regularization
φm = (1−α)/2·‖β‖² + α·‖β‖₁ on the depth-weighted model. α → 1 gives compact bodies, α → 0 smooth ones. The coordinate-descent solver computes the whole λ path from λmax and picks λ on it (L-curve by default); it needs gravity or magnetic data. On our magnetic synthetic, α ≈ 0.8 with wS1 recovered the body best (wS2 pushed it too deep). There is no smoothness term, so norms and αx,y,z do not apply. Joint jobs still use L2.
The focusing parameter e = scale × this percentile of |∇m| of the L2 model (default scale: 1 for MGS, 0.1 for TV), fixed once reweighting starts. MGS gives blocky, sharp-edged bodies but is very sensitive to e; set an upper property bound when you can. TV is milder: piecewise-smooth models.
φm = αs‖W m‖² + Σ αi‖W ∂im‖²: classic smooth least-squares inversion with sensitivity (depth) weighting. It gives smooth, blurred models with underestimated amplitudes; use it as a baseline or when no sharp contacts are expected. αx,y,z are length scales relative to αs, as for the other methods.
Model style (norms)
Regularization weights α
αx,y,z are length scales (SimPEG uses (α × smallest cell)² for the gradient terms). With αs as small as 0.0001 the smallness term hardly acts and sparse models turn into vertical columns that reach the bottom of the mesh; αs ≈ 0.1–1 gives compact bodies.
Depth weighting
Depth weighting sets the model-norm weight (z + z₀)−β/2 below the stations: β = 2 is Li & Oldenburg's value for gravity (3 for magnetics), and a smaller β keeps the model shallower. Unlike sensitivity weighting it does not make the padding cells cheap. Not used by L1–L2, whose weighting is set above.
Trade-off parameter (β / λ)
L-curve and GCV do not rely on the data errors; each runs a sweep of fixed-β inversions (about 15 extra runs) unless the L1–L2 λ path already provides it. On our synthetics the L-curve matched χ² = N for sparse models, while GCV tended to over-fit. GCV needs gravity or magnetic data. Joint jobs use χ² = N.

Geology constraintsoptional — rock units as a reference model, for a single gravity or magnetic inversion
Drop the constraint spec (.json) and the files it names
rock samples .csv · boreholes or map .shp (with .dbf .shx .prj) or .geojson
Each unit gets a value (a density contrast relative to the Bouguer reduction density, or a susceptibility) — from the mean of its rock samples, or given — and a range. The inversion starts from these values, is pulled towards them more strongly where the geology is known (the unit's weight), and keeps each unit within its range; elsewhere it is free. Units are placed by the rock samples (the column under each, to a depth), boreholes (along each hole), interpreted bodies (a polygon between two depths, optionally dipping) or map polygons. The data still decide: compare the misfit with and without the constraints. Format: docs/geology_constraints.md; an example: examples/output/karnataka_gravity/geology/karnataka_geology.json.
